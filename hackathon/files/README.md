# Hackathon pack · AI in Action for Medical Affairs

October 13–14, 2026 · Convene (2nd floor), Two Commerce Square, 2001 Market St, Philadelphia · Host and keynote: Vivek Mukhatyar · Companion site: https://aiinaction.up.railway.app

Everything facilitators and teams need for the build afternoon (Day 1, 1:45–5:00 PM) and the final presentations (Day 2, 9:00–11:00 AM). Four verticals, one team each.

## For facilitators

| File | What it is |
|---|---|
| [AI-in-Action-Hackathon-Facilitator-Guide.docx](AI-in-Action-Hackathon-Facilitator-Guide.docx) | All four guides in one formatted Word document, with the two-day overview and the Day 2 run of show |
| [01-publications-brain.md](01-publications-brain.md) | 01 Publications Brain: agenda and facilitator guide |
| [02-insights-engine.md](02-insights-engine.md) | 02 Insights Engine: agenda and facilitator guide |
| [03-congress-monitor.md](03-congress-monitor.md) | 03 Congress Monitor: agenda and facilitator guide |
| [04-field-intelligence-engine.md](04-field-intelligence-engine.md) | 04 Field Intelligence Engine: agenda and facilitator guide |

Each guide has: the challenge and a sharpened problem prompt; a suggested, minute-level Day 1 afternoon agenda (set up Grok Bot and skills · warm-up missions · workflow ideation · the hack) with "done looks like" for each block; the Day 2 plan; recommended missions and skills with links; the practice data files that fit; three Efficiency and three Opportunity AI ideas; a suggested swarm (lead agent, sub-agents, skills, hand-offs, two human gates); a walk-around question bank; pitfalls and unblocks; and an impact worksheet.

## Timing at a glance

- **Day 1, 1:45–5:00 PM (suggested, optional):** 1:45 set up Grok Bot and load skills (30 min) · 2:15 warm-up missions (40) · 2:55 workflow ideation (45) · 3:40 the hack (80). No formal share-out at 5:00; facilitators walk around and ask questions. 5:00 cocktail reception.
- **Day 2, 9:00–11:00 AM:** 9:00–9:38 final build and rehearsal · teams present 01→04 from 9:40 (about 9:40 / 10:00 / 10:20 / 10:40), about 20 minutes each including a few questions, before the 11:00 WPP demo.
