Handle the enquiry queue

What it does. Triage the enquiries, surface potential safety issues and draft responses supported by the fictional sources. Do not infer other-country approval or send responses.

1Paste this into Grok Bot

Pick the practice data, then copy.

2What you need

  • Grok Bot, or any agent that can read GitHub (set-up).
  • Nothing to download: the agent fetches the synthetic files itself (data).
  • About 15–20 minutes.

Files it reads (3):

  • medical-information-enquiries.csv
  • product-profile.md
  • structured-evidence-table.csv

3The steps

  1. Paste the prompt into Grok Bot (or any agent). It loads medical-affairs-foundations and the lead skill medical-information-response.
  2. It scans the data for possible safety findings first and tells you about any before doing anything else.
  3. medical-information-response does the core task: Draft responses to unsolicited medical enquiries from healthcare professionals, patients and payers, and build the standard response documents and FAQ library behind them.
  4. deliverable-quality-review checks the draft independently and the agent fixes what it finds.
  5. It hands you the deliverables as designed files, marked as drafts. You review and decide.

4Where you decide

  • Safety scan first Scan human-sourced records for possible safety, PQC or special-situation findings before analysis (AGENTS.md).
  • You decide Outputs are drafts for qualified human review; the human is the final judge (AGENTS.md).

You get

  • Triage register
  • Draft response and gap log
  • Simulated safety routing
